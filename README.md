SOCIAL OS

A social media management web app that runs entirely in your browser. Plan brands, strategy, campaigns, and content in one place, with no paid tools, no API keys, and no server.

Built as a portfolio project in digital marketing, social media strategy, and AI-powered product development.

Why this exists

Most social media tools are paid, cloud-based, and spread across several apps. SOCIAL OS keeps the whole workflow in one clean workspace that costs ₹0 to build, host, and use.

Modules
Module	Purpose
Overview	A snapshot of your brands, campaigns, and upcoming content
Brand Studio	Define each brand's voice, audience, and visual identity
Strategy Lab	Build and document a social media strategy per brand
Campaign Planner	Plan campaigns with goals, timelines, and deliverables
Content Studio	Draft and organise posts and ideas
Content Calendar	Schedule content across dates and platforms
Analytics Lab	Log and review performance results you enter yourself
Settings	Preferences, backup, and export/import
Principles
₹0 budget. Free tools and free hosting only.
No paid APIs and no API keys for any core feature.
Local-first. Your data is stored in your browser (IndexedDB), not on a server.
Backup and export. Download your data and restore it any time.
No fake features and no invented results. Analytics reflect only what you enter.
Design

An editorial look: deep burgundy, dark wine red, near-black, and warm ivory, with restrained pale yellow or muted green accents.

Getting started

Fill in the commands below to match the final project setup.

bash
# 1. Clone the repository
git clone https://github.com/<your-username>/social-os.git
cd social-os

# 2. Install dependencies (skip if the project is plain HTML/CSS/JS)
npm install

# 3. Run locally
npm run dev

If the project is plain HTML, JS, and CSS, open index.html in your browser instead.

Deploy for free

Any free static host works, for example Cloudflare Pages, GitHub Pages, or Netlify.

Push this repository to GitHub.
Connect the repository to your host.
Set the build command and output folder for your setup (for plain HTML there is no build step).
Deploy.
Your data and privacy

All data lives in your own browser. Nothing is sent to a server. Clearing your browser's site data will erase it, so use Settings → Export to keep a backup.
